  划分标准的核心公式

  ┌─────────────────────────────────────────────────┐
  │  ID3: 信息增益                                    │
  │                                                  │
  │  H(D) = -Σ pₖ log₂(pₖ)          ← 信息熵         │
  │  Gain(D,A) = H(D) - H(D|A)      ← 选最大的       │
  │                                                  │
  │  问题: 偏向取值多的特征 (如"编号"列)                  │
  └──────────────────────┬──────────────────────────┘
                         │ 改进
                         ▼
  ┌─────────────────────────────────────────────────┐
  │  C4.5: 信息增益率                                  │
  │                                                  │
  │  GainRatio(D,A) = Gain(D,A) / H_A(D)            │
  │                                                  │
  │  H_A(D) = -Σ (|Dᵥ|/|D|) log₂(|Dᵥ|/|D|)        │
  │            ↑ 固有值(intrinsic value)               │
  │                                                  │
  │  用固有值做分母，惩罚取值多的特征                      │
  └─────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────┐
  │  CART: Gini 系数                                  │
  │                                                  │
  │  Gini(D) = 1 - Σ pₖ²             ← 不纯度        │
  │  Gini(D,A) = (|D₁|/|D|)·Gini(D₁)               │
  │            + (|D₂|/|D|)·Gini(D₂) ← 选最小的       │
  │                                                  │
  │  优势: 不需要对数运算，计算更快                       │
  └─────────────────────────────────────────────────┘

● 决策树分类的计算过程

  核心流程：三种树完全一致

  ┌─────────────────────────────────────────────────────────────┐
  │              所有决策树的分类流程（训练 + 预测）                  │
  │                                                              │
  │   训练阶段                          预测阶段                   │
  │   (建树)                           (用树)                     │
  │                                                              │
  │   ┌──────────┐                     ┌──────────┐              │
  │   │ 全部数据  │                     │ 新样本 x  │              │
  │   └────┬─────┘                     └────┬─────┘              │
  │        ▼                                ▼                     │
  │   ┌──────────┐                     ┌──────────┐              │
  │   │选最优特征 │ ← 这一步不同！         │从根出发   │              │
  │   │进行分裂   │                     │逐层判断   │              │
  │   └────┬─────┘                     └────┬─────┘              │
  │        ▼                                ▼                     │
  │   ┌──────────┐                     ┌──────────┐              │
  │   │数据分到   │                     │到达叶子   │              │
  │   │子节点     │                     │节点       │              │
  │   └────┬─────┘                     └────┬─────┘              │
  │        ▼                                ▼                     │
  │   ┌──────────┐                     ┌──────────┐              │
  │   │递归重复   │                     │输出该叶子  │ ← 这一步     │
  │   │直到停止   │                     │的类别     │   也有差异    │
  │   └──────────┘                     └──────────┘              │
  │                                                              │
  │   ★ 唯一不同的地方：选最优特征的"评分标准"                       │
  │   ★ 其余骨架完全一样                                           │
  └─────────────────────────────────────────────────────────────┘

  三种打分方式

  ┌────────────────────────────────────────────────────────────────┐
  │ ID3 打分 —— 信息增益 (越大越好)                                   │
  │                                                                 │
  │ 第1步: 算分裂前的混乱度(熵)                                       │
  │                                                                 │
  │   H(D) = -( 6/10·log₂(6/10) + 4/10·log₂(4/10) )              │
  │        = 0.971 bits                                             │
  │                                                                 │
  │ 第2步: 算分裂后的混乱度                                           │
  │                                                                 │
  │   以"湿度"为例:                                                   │
  │   H(D|湿度) = 5/10·H(高) + 5/10·H(正常)                         │
  │               ↑权重        ↑子集的熵                              │
  │                                                                 │
  │   H(高)   = -(1/5·log₂(1/5) + 4/5·log₂(4/5)) = 0.722         │
  │   H(正常) = -(5/5·log₂(5/5) + 0/5·...)        = 0  ← 纯了!    │
  │                                                                 │
  │   H(D|湿度) = 0.5 × 0.722 + 0.5 × 0 = 0.361                   │
  │                                                                 │
  │ 第3步: 增益 = 分裂前 - 分裂后                                      │
  │                                                                 │
  │   Gain(湿度) = 0.971 - 0.361 = 0.610  ✓ 大 → 好                 │
  │   Gain(天气) = 0.971 - 0.888 = 0.083                            │
  │   Gain(温度) = 0.971 - 0.911 = 0.060                            │
  │                                                                 │
  │   ★ 选 Gain 最大的 → 湿度                                        │
  └────────────────────────────────────────────────────────────────┘

  ┌────────────────────────────────────────────────────────────────┐
  │ C4.5 打分 —— 信息增益率 (越大越好)                                 │
  │                                                                 │
  │ 在 ID3 的基础上多除一个"固有值":                                    │
  │                                                                 │
  │   GainRatio(A) = Gain(A) / H_A(D)                              │
  │                                                                 │
  │ 固有值 = 特征自身取值的熵                                          │
  │                                                                 │
  │   H_天气(D) = -(4/10·log₂(4/10) + 3/10·log₂(3/10)             │
  │              + 3/10·log₂(3/10))                                 │
  │            = 1.571  ← 取值多，固有值大，被惩罚                      │
  │                                                                 │
  │   H_湿度(D) = -(5/10·log₂(5/10) + 5/10·log₂(5/10))            │
  │            = 1.000  ← 取值少，固有值小                             │
  │                                                                 │
  │   GainRatio(天气) = 0.083 / 1.571 = 0.053                      │
  │   GainRatio(湿度) = 0.610 / 1.000 = 0.610  ✓                   │
  │                                                                 │
  │   ★ 选 GainRatio 最大的 → 湿度                                   │
  └────────────────────────────────────────────────────────────────┘

  ┌────────────────────────────────────────────────────────────────┐
  │ CART 打分 —— Gini 系数 (越小越好)                                 │
  │                                                                 │
  │ 完全不用 log，改用平方:                                            │
  │                                                                 │
  │   Gini(D) = 1 - Σ pₖ²                                          │
  │           = 1 - (6/10)² - (4/10)²                               │
  │           = 1 - 0.36 - 0.16 = 0.48                              │
  │                                                                 │
  │ 注意: CART 只做二分！"湿度=高?" → Yes / No                         │
  │                                                                 │
  │   Gini(D, 湿度=高)                                               │
  │     = 5/10 · Gini(高) + 5/10 · Gini(正常)                       │
  │     = 0.5 · (1 - (1/5)² - (4/5)²) + 0.5 · 0                   │
  │     = 0.5 · 0.32 + 0                                            │
  │     = 0.16  ✓ 小 → 好                                           │
  │                                                                 │
  │   ★ 选 Gini 最小的分裂方式                                        │
  └────────────────────────────────────────────────────────────────┘

  第二步：到叶子节点后怎么分类

  ┌─────────────────────────────────────────────────────────────┐
  │  三种树在叶子节点的预测方式                                      │
  ├───────────┬─────────────────────────────────────────────────┤
  │           │                                                  │
  │  ID3      │  多数投票 (majority vote)                         │
  │           │  叶子里哪个类别多，就预测哪个                         │
  │           │                                                  │
  │           │  叶子: [✓✓✓✓✗] → 预测 ✓  (4:1)                  │
  │           │                                                  │
  ├───────────┼─────────────────────────────────────────────────┤
  │           │                                                  │
  │  C4.5     │  多数投票 (同上)                                   │
  │           │  但缺失值样本按概率分配到各分支，权重参与投票            │
  │           │                                                  │
  │           │  叶子: [✓✓✓(0.6个✗)] → 预测 ✓                    │
  │           │                                                  │
  ├───────────┼─────────────────────────────────────────────────┤
  │           │                                                  │
  │  CART     │  分类: 多数投票 (同上)                              │
  │  (分类)   │  叶子: [✓✓✓✗✗] → 预测 ✓  (3:2)                  │
  │           │                                                  │
  ├───────────┼─────────────────────────────────────────────────┤
  │           │                                                  │
  │  CART     │  回归: 取平均值                                    │
  │  (回归)   │  叶子: [3.2, 4.1, 3.8] → 预测 3.7               │
  │           │                                                  │
  └───────────┴─────────────────────────────────────────────────┘

  结论: 叶子节点预测方式 → 基本一样，都是多数投票

  第三步：什么时候停止分裂

  递归分裂的停止条件（三种树大同小异）:

      ┌──────────┐
      │ 继续分裂？│
      └────┬─────┘
           │
      ┌────▼──────────────────────┐   Yes
      │ 叶子全是同一类？            ├────────► 停！已经纯了
      │ (如全是✓ 或全是✗)          │
      └────┬──────────────────────┘
           │No
      ┌────▼──────────────────────┐   Yes
      │ 没有可用特征了？            ├────────► 停！多数投票
      │ (ID3/C4.5: 特征用完)       │
      │ (CART: 可重复用，看深度)     │
      └────┬──────────────────────┘
           │No
      ┌────▼──────────────────────┐   Yes
      │ 样本数太少？               ├────────► 停！多数投票
      │ (如 min_samples_leaf)     │
      └────┬──────────────────────┘
           │No
      ┌────▼──────────────────────┐   Yes
      │ 达到最大深度？              ├────────► 停！多数投票
      │ (max_depth)               │
      └────┬──────────────────────┘
           │No
           ▼
      继续选特征、继续分裂

  总结

  ┌─────────────────────────────────────────────────────┐
  │                                                      │
  │  相同点 (骨架一致):                                    │
  │  ├─ 都是贪心递归分裂 (每次选当前最优)                     │
  │  ├─ 叶子节点都用多数投票做分类                           │
  │  └─ 停止条件基本相同                                   │
  │                                                      │
  │  不同点 (只有一个地方不同):                               │
  │  └─ "当前最优"的评分标准                                │
  │      ├─ ID3:  信息增益      (熵的下降量)                │
  │      ├─ C4.5: 信息增益率    (增益/固有值)               │
  │      └─ CART: Gini 系数    (1 - Σpₖ²)               │
  │                                                      │
  │  ★ 一句话: 骨架完全一样，只是"打分函数"不同               │
  │                                                      │
  └─────────────────────────────────────────────────────┘

  所以可以把决策树理解为一个框架，ID3/C4.5/CART
  只是往这个框架里插入了不同的"评分卡"。建树逻辑、预测逻辑、停止条件都是通用的。

● CART 处理缺失值：替代分裂（Surrogate Split）

  核心思想

  ┌──────────────────────────────────────────────────────────────┐
  │                                                               │
  │  CART 的思路：                                                 │
  │                                                               │
  │  "如果首选特征的值缺失了，                                       │
  │   我提前准备好几个替补特征，                                      │
  │   用替补来模拟首选的分裂结果"                                     │
  │                                                               │
  │  就像足球比赛的替补队员 —— 首发上不了场，替补顶上                   │
  │                                                               │
  └──────────────────────────────────────────────────────────────┘

  ┌──────────────┬─────────────────────┬─────────────────────────┐
  │              │      C4.5           │        CART              │
  ├──────────────┼─────────────────────┼─────────────────────────┤
  │ 方法名称      │ 概率分配             │ 替代分裂                  │
  │              │ (Fractional Cases)  │ (Surrogate Split)       │
  ├──────────────┼─────────────────────┼─────────────────────────┤
  │              │ 把缺失样本按比例      │ 缺失了就换一个特征         │
  │ 核心思路      │ 同时送入每个分支      │ 走替代路径                │
  │              │ 带权重参与后续计算     │ 只走一条路                │
  ├──────────────┼─────────────────────┼─────────────────────────┤
  │              │                     │                          │
  │ 训练时        │ 缺失样本按比例分配    │ 缺失样本不参与主分裂计算    │
  │              │ 到各分支(权重<1)      │ 用非缺失样本算替代分裂      │
  │              │                     │                          │
  ├──────────────┼─────────────────────┼─────────────────────────┤
  │              │                     │                          │
  │ 预测时        │ 走所有分支           │ 只走一条替代分支            │
  │              │ 加权投票合并结果      │ 得到唯一确定结果            │
  │              │                     │                          │
  ├──────────────┼─────────────────────┼─────────────────────────┤
  │ 样本走向      │ "分身术"            │ "换条路"                  │
  │              │ 一个样本分成多份      │ 一个样本始终完整            │
  ├──────────────┼─────────────────────┼─────────────────────────┤
  │ 计算开销      │ 较小                │ 较大(每个节点要算替代列表)   │
  ├──────────────┼─────────────────────┼─────────────────────────┤
  │ 可解释性      │ 较差(概率分身)       │ 较好(明确走了哪条路)        │
  └──────────────┴─────────────────────┴─────────────────────────┘

  ┌─────────────────────────────────────────────────────────────┐
  │                                                              │
  │  场景: 你要去一个地方，GPS 说"在红绿灯右转"                      │
  │                                                              │
  │  C4.5 的做法:                                                 │
  │  → 红绿灯被挡住看不见？                                        │
  │  → "我 60% 觉得该右转，40% 觉得该左转"                          │
  │  → 灵魂分裂，两边都走一点，最后加权合并                           │
  │                                                              │
  │  CART 的做法:                                                  │
  │  → 红绿灯被挡住看不见？                                        │
  │  → "没关系，我提前记了替代地标——看到加油站就右转"                   │
  │  → 看到加油站了！右转！                                        │
  │  → 如果加油站也看不到？"还有备用——路边有棵大树就右转"               │
  │  → 明确走一条路，不分身                                        │
  │                                                              │
  └─────────────────────────────────────────────────────────────┘

  一句话总结

  ┌─────────────────────────────────────────────────────────────┐
  │                                                              │
  │  CART 替代分裂的本质:                                          │
  │                                                              │
  │  训练时 → 每个节点不仅选出最优分裂，还排好一队"替补分裂"           │
  │  预测时 → 主特征缺失就依次尝试替补，直到找到一个有值的             │
  │                                                              │
  │  关键: 替补的排序标准 = 和主分裂的分组一致性(不是 Gini)           │
  │                                                              │
  └─────────────────────────────────────────────────────────────┘

  有放回抽样的效果:
  · 每个子集大约包含原数据的 63.2% 的不重复样本

  ┌─────────────────────────────────────────────────────────────┐
  │                                                              │
  │                 随机森林 = 两层随机                             │
  │                                                              │
  │  第1层: 数据随机 (Bootstrap)                                   │
  │  ┌──────────┐   每棵树看到的样本不同                            │
  │  │■□■■□■□■■□│   ~ 63.2% 的原始样本                           │
  │  └──────────┘                                                │
  │       +                                                      │
  │  第2层: 特征随机 (Feature Subsampling)                         │
  │  ┌──────────┐   每次分裂可选的特征不同                           │
  │  │■ □ ■ □ □ │   m = √M 个候选                                │
  │  └──────────┘                                                │
  │       ‖                                                      │
  │       ▼                                                      │
  │  每棵树都"见识不同，思路不同"                                    │
  │  → 犯的错误也不同                                              │
  │  → 投票/平均后，错误互相抵消                                    │
  │                                                              │
  │       单棵树         →  高方差、易过拟合                         │
  │       多棵树投票      →  低方差、不易过拟合                       │
  │                                                              │
  │  数学上: Var(平均) = Var(单棵) / T                              │
  │  (当树之间独立时，T棵树的方差降为 1/T)                            │

  │  对 x₁ 来说: 树#2 没用它训练 → 用树#2 预测 x₁ 是公平的          │
  │  对 x₂ 来说: 树#1 没用它训练 → 用树#1 预测 x₂ 是公平的          │
  │  对 x₄ 来说: 树#1,#2 没用它  → 用树#1,#2 投票预测 x₄           │
  │                                                              │
  │  汇总所有样本的 OOB 预测 → OOB 准确率                           │
  │                                                              │
  │  ★ 不需要额外划分验证集！Bootstrap 天然提供了！                   │
  │                                                              │
  └─────────────────────────────────────────────────────────────┘

  随机森林 vs 单棵 CART

  ┌──────────────┬──────────────────┬──────────────────────────┐
  │              │    单棵 CART      │      随机森林              │
  ├──────────────┼──────────────────┼──────────────────────────┤
  │ 基学习器      │  1 棵 CART       │  T 棵 CART (通常 100~500) │
  ├──────────────┼──────────────────┼──────────────────────────┤
  │ 数据          │  全量            │  Bootstrap 子集           │
  ├──────────────┼──────────────────┼──────────────────────────┤
  │ 特征选择      │  每次从全部M个选  │  每次从随机m个选           │
  ├──────────────┼──────────────────┼──────────────────────────┤
  │ 剪枝          │  需要(CCP)       │  不需要！让树充分生长      │
  ├──────────────┼──────────────────┼──────────────────────────┤
  │ 方差          │  高(不稳定)      │  低(多树平均)             │
  ├──────────────┼──────────────────┼──────────────────────────┤
  │ 偏差          │  低              │  低(不剪枝，保持低偏差)    │
  ├──────────────┼──────────────────┼──────────────────────────┤
  │ 过拟合        │  容易            │  不容易(树越多越安全)      │
  ├──────────────┼──────────────────┼──────────────────────────┤
  │ 可解释性      │  高(画一棵树)     │  低(几百棵树没法画)       │
  ├──────────────┼──────────────────┼──────────────────────────┤
  │ 训练速度      │  快              │  可并行，不算慢           │
  ├──────────────┼──────────────────┼──────────────────────────┤
  │ 超参数        │  max_depth 等    │  + n_estimators(树数量)  │
  │              │                  │  + max_features(m)       │
  └──────────────┴──────────────────┴──────────────────────────┘

  从 CART 到随机森林的完整链条

     单棵决策树                   Bagging                    随机森林
     ──────────                  ────────                   ──────────

     1棵树                       T棵树                      T棵树
     全部数据                     数据随机                    数据随机
     全部特征                     全部特征                    特征也随机
                                                            ↑
     ┌──┐                    ┌──┬──┬──┐               ┌──┬──┬──┐
     │🌲│                    │🌲│🌲│🌲│               │🌴│🌵│🎄│
     └──┘                    └──┴──┴──┘               └──┴──┴──┘
                              树长得像                    树长得各不相同
     问题:                    (强特征总被选)
     方差大                                             效果:
     易过拟合                  部分解决                    每棵树"见识不同"
                              → 方差有所下降               → 方差大幅下降
                                                         → 几乎不过拟合

     ─────────── 演进方向 ──────────────────────────────────►

     核心公式:
     随机森林 = CART × T棵 + Bootstrap采样 + 特征子采样 + 多数投票

  一句话总结

  ┌─────────────────────────────────────────────────────────────┐
  │                                                              │
  │  CART 是"一个聪明但偏激的专家"                                 │
  │                                                              │
  │  随机森林是"一群各有所长的普通专家，投票决策"                     │
  │                                                              │
  │  从 CART → 随机森林:                                          │
  │  不是让一棵树更强，而是让很多棵"不同的"树合作                     │
  │                                                              │
  │  差异性是关键 —— 没有差异的投票毫无意义                          │
  │  两层随机(数据+特征)就是制造差异的手段                           │
  │                                                              │
  └─────────────────────────────────────────────────────────────┘
